Collector sends data (web form / SMS / WhatsApp)
          │
          ▼
     INGEST CONTROLLER
  (receives raw input from outside world)
          │
          ▼ (for SMS only)
       SMS PARSER
  (translates raw text into structured data)
          │
          ▼
    NORMALISER SERVICE
  (validates everything, builds the event)
          │
          ▼
  CONTRIBUTIONS SERVICE
  (saves to database)

AUDIT SERVICE does two things:
1. WRITE  — record every contribution as a tamper-evident log entry
2. VERIFY — walk through all entries and prove none were modified

FULL PICTURE OF ONE CONTRIBUTION FLOWING THROUGH AUDIT
Contribution received
        ↓
Normaliser saves to database
        ↓
Job pushed to queue
        ↓
Processor picks up job
        ↓
AuditService.writeAuditLog(event)
        ↓
Get previous entry → prevHash = "a3f9b2c1..."
        ↓
Build entryData snapshot
        ↓
Compute entryHash = SHA256(prevHash + entryData)
        ↓
Compute hmacSig = HMAC(entryHash, secretKey)
        ↓
Save: prevHash + entryData + entryHash + hmacSig
        ↓
Chain grows by one link

**
 * JwtAuthGuard protects routes from unauthenticated access.
 *
 * Apply it to a controller or individual endpoint:
 *
 * Protect entire controller:
 *   @UseGuards(JwtAuthGuard)
 *   @Controller('groups')
 *   export class GroupsController {}
 *
 * Protect single endpoint:
 *   @UseGuards(JwtAuthGuard)
 *   @Get(':id/summary')
 *   getSummary() {}
 *
 * What happens when a request hits a guarded route:
 *   1. Guard extracts JWT from Authorization header
 *   2. Passes to JwtStrategy for signature verification
 *   3. JwtStrategy.validate() fetches collector from database
 *   4. If all checks pass → req.user is populated, request proceeds
 *   5. If any check fails → 401 Unauthorized, request stops here
 */

 import { Injectable } from '@nestjs/common';
import { ConfigService } from '@nestjs/config';
import { neon } from '@neondatabase/serverless';
import { drizzle } from 'drizzle-orm/neon-http';
import * as schema from '../schema';

@Injectable()
export class DrizzleDbService {
    db: ReturnType<typeof drizzle<typeof schema>>;

  constructor(private config: ConfigService) {
    const url = this.config.getOrThrow<string>('DATABASE_URL');
    const sql = neon(url, { fetchOptions: { timeout: 30000 } });
    this.db = drizzle(sql, { schema });
  }
}
